# タイピングスタジアム

小学生向けのタイピング×野球ゲーム。打つ速さとミスの数で、ホームラン・ヒット・アウトが決まります。

https://shintaro60320-blip.github.io/typing-stadium/

ブラウザで開くだけで遊べます（キーボードのあるパソコンで）。ランキングと設定は、遊んだパソコンのブラウザの中だけに残り、どこにも送信しません。

PC の Chrome / Edge なら「アプリとしてインストール」できます（アドレスバー右はしのインストールのボタン、またはメニューの「アプリをインストール」）。入れるとデスクトップのアイコンから起動でき、ネットが無くても遊べます。
